# AI 味小字特征库与人味化改写字典 (`ai-slop-dictionary.md`)

本文档定义 `ai-clean-master` 在扫描 PPT、图片（海报/信息图）、网站（HTML/React/Vue）及文档（Docx/MD）时的**四大类 AI 味小字识别准则**、**统一去黑话底线词表**，以及**四大场景自适应人味语感改写范例**。

---

## 一、四大类「AI 味小字」跨载体识别准则

### 1. 顶部 / 卡片伪英文与八股眉题（Kickers & Pill Badges）
AI 模板最喜欢在大标题上方或卡片左上角塞一行毫无信息增量的小字，通常还套着圆角胶囊框（Pill/Badge）：
- **典型文本特征**：
  - 伪英文编号与标签：`SECTION 01`, `PART 02`, `CHAPTER I`, `CORE INSIGHT`, `STRATEGIC OVERVIEW`, `KEY TAKEAWAY`, `AI-POWERED`, `NEXT-GEN PLATFORM`, `SYSTEM ONLINE`, `FEATURE MATRIX`, `01 // OVERVIEW`。
  - 八股四字眉题：`核心赋能模块`、`战略顶层设计`、`多维价值闭环`、`创新驱动引擎`、`痛点深度剖析`。
- **排版/代码特征**：
  - **PPT**：字号 `<= 14pt`、位于页面顶部（`top < 18%`）或卡片顶部、常带字符间距加宽或全大写，背后紧贴一个圆角矩形/胶囊框 `AutoShape`。
  - **网站**：`<span class="... rounded-full px-3 py-1 text-xs ...">✨ ...</span>` 或标题上方带 `uppercase tracking-wider text-xs` 的微标签。
  - **图片**：标题正上方的小号胶囊色块配反白小字。
- **处理准则**：**连盒带字直接删除**（将文字节点与背后的胶囊色块/边框一并移除）。唯一例外是用户明确需要保留简单的纯数字序号（如 `01`、`02`）。

### 2. 卡片内同义反复的凑数解释小字（Redundant Micro-Explanations）
AI 生成卡片时，为了把版面填满，往往在卡片主标题下方硬凑 1~3 行小字，内容只是把主标题用废话复述一遍：
- **典型病灶示例**：
  - 卡片标题：`毫秒级故障响应`
  - 下方小字（10pt / `text-xs`）：`通过引入高效的实时监测机制，实现毫秒级别的快速故障响应与异常处置能力。`（**完全没有新增任何事实、参数或原理！**）
- **判定法则（信息增量测试）**：
  - 把下方小字遮住，只看卡片标题，读者获得的信息量是否一样？
  - 如果小字只是把标题加了“通过…实现了…”、“多维度提升…”、“有效保障了…”，判定为 **100% 凑数小字**。
  - 如果小字里包含**唯一的具体参数/硬件型号/真实数据**（如 `采用 STM32F4 主控，响应延迟 < 8ms`），则**将该关键事实提炼合并到主标题/核心短句中**，再删掉多余的废话小字。
- **处理准则**：删除凑数小字段落/文本框，并将卡片内保留的核心语句**字号提权放大 + 调整行距/垂直居中**。

### 3. 页脚 / 底栏的假大空总结与免责废话（Footer Slop & Disclaimers）
AI 生成 PPT 和海报时，常在底部横跨放一条深色或浅色底栏，写上一句正确的废话或免责声明：
- **典型文本特征**：
  - 假大空总结：`本页核心洞察：通过全链路协同实现高质量发展的闭环`、`核心结论：以数字化抓手驱动产业范式转移`、`Takeaway: Empowering seamless digital transformation`。
  - 免责与水印小字：`注：以上数据仅为演示参考，具体以实际运行为准`、`Generated by AI`、`仅供内部交流参考`、无意义的假页码/假网址/假命令行状态栏（`STATUS: READY | LATENCY: 12ms`）。
- **处理准则**：**连盒带字直接删除**（底部横条 `AutoShape` / `<footer>` 废话条连同文字一起清掉，释放页面底部呼吸空间）。

### 4. 伪造的装饰性微数据 / 角标与表情噪音（Fake Micro-Metrics & Emoji Slop）
- **典型特征**：
  - 未经用户提供、AI 自己编造用来撑版面的微角标：`+99.8%`、`EFFICIENCY +300%`、`INDEX: A+`、`ACCURACY 99.9%`。
  - 网页与卡片里泛滥成灾的装饰 Emoji：`✨`、`🚀`、`💡`、`⚡`、`🔥`、`🎯`、`🌐`。
- **处理准则**：
  - Emoji 噪音一律清除；
  - 伪造微数据在 `grill-me` 阶段向用户核实：若是 AI 瞎编的装饰角标，连同角标小框一起删除；若是用户的真实实验/业务数据，则保留数字并改写为具体指标说明（如 `实测分选准确率 96.4%`）。

## 二、统一「去 AI 黑话」底线词表（中英双语 / Bilingual Buzzword Blacklist）

### 1. 中文高频 AI 黑话与八股套路

无论什么场景，以下 AI 高频黑话与机械句式默认列入黑名单，一经扫描命中必须改写：

| 禁用 AI 黑话 / 套路 | 为什么 AI 味重 | 人味化替换方向 |
|---|---|---|
| **赋能**（如：AI 赋能、科技赋能） | 空洞无物，看不出到底做了什么具体动作 | 改为具体动作：**帮…省下时间、自动识别、直接控制、把…提速** |
| **抓手 / 着力点 / 切入点** | 典型公文套话，掩盖具体方法 | 改为具体工具或步骤：**核心办法、第一步先做…、靠这套机构解决** |
| **闭环**（如：全链路闭环、生态闭环） | 万物皆闭环，毫无细节 | 写明从哪一步到哪一步：**从采样、识别到分拣一气呵成 / 全程自动完成** |
| **全链路 / 全方位 / 多维度 / 深层次** | 凑字数形容词，删掉完全不影响原意 | **直接删掉**，或写出具体哪几个方面（如：从机械、电控和算法三方面） |
| **底层逻辑 / 顶层设计 / 范式转移** | 故作高深，脱离实际内容 | 改为：**核心原理、根本原因、整体结构、换了一套新做法** |
| **生态体系 / 矩阵 / 协同共振 / 组合拳** | 商业吹嘘感极强，尤其在高校/工程中极假 | 改为：**整套系统、配套方案、几个模块配合工作** |
| **痛点剖析 / 破局之道 / 未来展望** | 千篇一律的四字章节名 | 改为有信息量的人话标题：**现在卡在哪？/ 我们的解决办法 / 下一步计划** |
| **基于…背景下，通过…方式，实现了…** | 翻译腔介词套娃，读起来喘不过气 | 改为主谓宾短句：**为了解决 X，我们用 Y 做到了 Z** |

### 2. English AI Slop & Buzzword Blacklist

| Banned English AI Slop | Why It Sounds Robotic | Humanized Replacement Direction |
|---|---|---|
| **Empower / Empowering / Unleash / Unlock** | Vague corporate filler with zero concrete action | Use concrete verbs: **Cut latency by 40%, automate X, let users do Y in 1 click** |
| **Delve into / Testament to / Rich tapestry** | Classic LLM cliché markers | Cut entirely; state the fact or finding directly |
| **Holistic ecosystem / End-to-end synergy** | Buzzword soup that hides how the system works | Name the actual components: **Camera + PLC controller + sorting arm working together** |
| **Paradigm shift / Game-changer / Cutting-edge** | Empty hype adjectives | Replace with measurable proof: **3x faster than manual sorting** |
| **Leverage / Utilize / Facilitate** | Overly formal bureaucratic verbs | Replace with **Use, Run, Build, Help** |
| **By leveraging X, we seamlessly achieve Y** | Formulaic AI sentence structure | **We built X so Y happens in 0.2 seconds** |

## 三、四大场景自适应「人味语感」改写指南

### 场景 1：竞赛路演 / 创客答辩风（挑战杯、大创、机器人/AI 竞赛、职规赛）
- **语感核心**：像一个真正泡在实验室自己焊板子、调代码的同学在向评委讲自己的作品。**讲真痛点、讲真动作、给真数据**。
- **Before（AI 味）**：
  > `[CORE INSIGHT]` 多维感知赋能智慧农业新生态
  > 本系统基于深度学习底层逻辑，通过全链路视觉识别抓手，构建了多维度果蔬分选闭环，有效赋能农户降本增效。
- **After（人味化）**：
  > **双目相机 + 轻量模型，0.2 秒挑出瑕疵果**
  > 传统人工挑果又慢又容易看走眼。我们自己搭了双目视觉暗箱，跑通了轻量化 YOLO 模型，单果识别只要 0.2 秒，比人工快 4 倍。

### 场景 2：工科实训 / 技术工程风（PLC 控制、机械设计、课程设计、工程技术评审）
- **语感核心**：**动词 + 硬件/结构名称 + 参数/动作结果**。干净利落，不抒情、不喊口号。
- **Before（AI 味）**：
  > `[SECTION 02]` 安全互锁机制的顶层设计与全方位保障
  > 通过软硬件双维度的深度融合，打造高可靠性的电机正反转控制矩阵，全面筑牢工业安全防线。
- **After（人味化）**：
  > **PLC 程序 + 接触器机械双重互锁，严防电源短路**
  > 正反转切换时如果两个接触器同时吸合会直接炸相间短路。我们在梯形图里串了常闭触点，外部接线又加了 KM1/KM2 机械互锁，双保险防误触。

### 场景 3：课堂教学 / 班会演讲风（高校班会、课前 10 分钟演讲、教学课件、经验分享）
- **语感核心**：**带「咱们 / 大家 / 你」主语**，用自然口语短句代替书面长难句，像站在讲台上看着台下同学说话。
- **Before（AI 味）**：
  > `[KEY TAKEAWAY]` 构建科学的时间管理体系以实现学业跃迁
  > 在碎片化信息时代背景下，通过精细化的日程颗粒度对齐，方能打破拖延症困局，赋能个人核心竞争力提升。
- **After（人味化）**：
  > **别让刷手机偷走你的晚自习：每天只抓最核心的 2 件事**
  > 大家是不是经常觉得忙了一整天，回宿舍却发现正事一件没干？其实不用列密密麻麻的计划表，每天早上只写下今天非做不可的 2 件事，干完再玩。

### 场景 4：干练商务 / 日常工作汇报风（项目周报、产品演示、方案提案）
- **语感核心**：**结论先行（一页一句大白话结论）**，少用形容词，直接交待「做了什么、结果怎样、需要什么支持」。
- **Before（AI 味）**：
  > `[STRATEGIC REVIEW]` Q3 阶段性成果复盘与全渠道增长引擎构建
  > 本季度通过多触点精细化运营组合拳，实现了用户转化链路的全方位跃升，达成高质量增长闭环。
- **After（人味化）**：
  > **三季度注册转化率提升 18%，主要靠简化了结账流程**
  > 我们把原来 4 步填写的注册表单砍到了 1 步手机验证，流失率当周就降了一半，带来 1.2 万新增付费用户。
